# hubo-wadamesh

**Hubo S3 与 Hubo P4 Mesh 终端**的固件，基于 [ALLFATHER-BV/wadamesh](https://github.com/ALLFATHER-BV/wadamesh)
（GPL-3.0）——它让触屏手持设备运行 [MeshCore](https://github.com/meshcore-dev/MeshCore)。

**状态：源码将在这里发布。**首个版本发布前，我们正在完成第三方许可证合规，并清理内部信息。
本仓库与 wadamesh 一样使用 GPL-3.0。

## 将发布的内容

- Hubo S3 终端（ESP32-S3）与 Hubo P4 终端（ESP32-P4）变体
- 中文界面与输入法
- 网状网络语音短讯（Codec2）
- 由 MeshLoRa C3 电台提供数据的 GPS 页
- Hubo-Tack 30-Pin 背包身份卡识别
